### 3. Committing Multiple Files (15 points)

```{r message = FALSE}
library(tidyverse)
fish <- read_csv("../data/Gaeta_etal_CLC_data.csv")

# only fish with scalelength > 1mm
fish |>
  filter(scalelength >= 1)

```
